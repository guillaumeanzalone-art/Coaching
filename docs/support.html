Assistance L'Araignée Coaching

À propos

L'Araignée Coaching est l'application utilisée par GA Coaching pour distribuer les programmations d'entraînement, suivre les séances et proposer les fonctionnalités de progression et RPG associées.

Besoin d'aide ?

Vous pouvez nous contacter pour :

  • un problème de connexion ;
  • un problème de synchronisation ;
  • une erreur concernant votre programme ;
  • une difficulté avec le suivi d'entraînement ;
  • une question sur les fonctionnalités RPG ;
  • une demande concernant vos données personnelles.

Contact : guillaumeanzalone@gmail.com

Accès à l'application

L'accès est réservé aux utilisateurs disposant d'un compte GA Coaching. Si votre compte n'est pas reconnu ou si vous avez perdu vos accès, contactez le support.

Suppression des données

Pour demander l'accès, la rectification ou la suppression de vos données et de votre compte, envoyez une demande à guillaumeanzalone@gmail.com .
