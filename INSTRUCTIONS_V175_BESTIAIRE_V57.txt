INSTALLATION SUPABASE
1. Ouvrir Supabase > SQL Editor.
2. Créer une nouvelle requête.
3. Copier tout PATCH_SUPABASE_V175_BESTIAIRE_V57.sql.
4. Cliquer sur Run.
5. Dans le tableau de contrôle "expected_count / actual_count", idéalement les
   neuf lignes affichent ok = true.
6. Aucun reset de progression n'est effectué.

INSTALLATION GITHUB / APP.JS
Le SQL suffit pour que le serveur tire les bonnes raretés et que le catalogue
Supabase soit corrigé.

Pour que le panneau de probabilités côté navigateur affiche lui aussi exactement
67,339 / 27 / 4 / 1 / 0,5 / 0,1 / 0,05 / 0,01 / 0,001 et pour corriger les
anciens alias Funk/Phonk, appliquer les changements contenus dans :
PATCH_APP_JS_V175_BESTIAIRE_V57.diff

Ensuite :
- commit app.js ;
- recharger le jeu avec Ctrl + F5.
